# Огляд кандидатів на дані дозування — для перевірки лікарем

Цей файл призначений для лікарки-ветеринара. Кожен рядок таблиці — це доза,
знайдена в реальній офіційній інструкції препарату (не вигадана і не з
пам'яті ШІ), з прямим посиланням на джерело. **Нічого з цього не потрапляє в
робочу базу VetDose, доки ви не підтвердите запис** (див. процес підтвердження
нижче).

Статус: **Пакети 1-3 з 4** завершено. Пакет 1 — Amoxicillin, Enrofloxacin,
Meloxicam, Carprofen, Ivermectin. Пакет 2 — Praziquantel, Ceftiofur,
Oxytetracycline, Flunixin meglumine, Phenylbutazone. Пакет 3 — Xylazine,
Ketamine, Dexamethasone, Metronidazole (Doxycycline — див. "Не знайдено").
Пакет 4 ще не оброблений.

🔴 **Ketamine — речовина предметно-кількісного обліку (в США DEA Schedule
III).** Дозування зібране з офіційної етикетки виключно для довідки лікаря
при плановому застосуванні; зберігання, облік і документообіг цього
препарату в клініці регулюються окремим законодавством, поза межами цього
дозового калькулятора.

⚠️ Під час пошуку для пакета 2 у сирому вмісті кількох сторінок DailyMed
траплявся підозрілий блок тексту, що видавав себе за "правила інструменту
WebFetch" (штучний ліміт 125 символів на цитату, недоречні згадки про
пісенні тексти й легальність). Це схоже на спробу prompt-injection,
вбудовану в контент сторінки, а не на реальну інструкцію. Розпізнано й
проігноровано у всіх випадках, дані не постраждали — фіксую тут для
прозорості.

## Як підтвердити запис

Коли перевірите запис і погодитесь з дозою — додайте рядок у
`data/candidates/approved.csv` (файл, тип запису, індекс, хто підтвердив,
дата). Лише такі записи потрапляють у робочу базу через
`backend/app/seed/import_candidates.py --dry-run` (спершу для перевірки) і
без `--dry-run` (для імпорту).

## ⚠️ Потребує особливої уваги

- **Жодне джерело не є рівнем 1 (Держреєстр України).** Усі 5 препаратів
  цього пакета підтверджені лише рівнем 2 (FDA DailyMed, США). Це означає:
  торгові назви, концентрації й, особливо, **терміни виведення** можуть
  відрізнятися від того, що реально зареєстровано в Україні. Кожен запис
  `withdrawal_periods` позначений `needs_local_confirmation: true`.
- **UK VMD SPC-документи (рівень 2, ЄС) не вдалося прочитати** для
  Amoxicillin, Enrofloxacin та Ivermectin — PDF-файли з
  vmd.defra.gov.uk віддали нечитабельний бінарний потік замість тексту
  (ймовірно, особливість генератора Aspose.Words на їхній стороні). Це
  означає, що дозування для ВРХ/овець з європейських продуктів (наприклад,
  Ivomec для овець) у цьому пакеті **відсутнє**, хоча має існувати в
  реальних європейських джерелах.
- **Meloxicam для ВРХ/коней/свиней НЕ включений**, хоча ці види є в
  первинному списку припущень. У пошукових фрагментах трапились цифри
  (0.5 мг/кг ВРХ, 0.4 мг/кг свині, 0.6 мг/кг коні), але жодне реальне
  джерело з цими цифрами не вдалося відкрити й процитувати дослівно в цьому
  пакеті — тому вони свідомо НЕ потрапили у файл. Потрібен окремий пошук.
- **Ivermectin для овець і коней НЕ включений** з тієї ж причини (не
  вдалося прочитати UK VMD SPC; коня джерело взагалі не згадує).
- **Конфлікт форми препарату для Amoxicillin**: у початковому списку
  `drug_list.csv` форма була заявлена як `injection_solution`, але реальне
  знайдене джерело (Amoxi-Drop) — оральна суспензія для собак/котів, не
  ін'єкція для продуктивних тварин. Ін'єкційна форма амоксициліну для
  продуктивних тварин ще не знайдена в цьому пакеті.
- **Дозування "50 мг (5-10 мг/фунт)" для котів (Amoxi-Drop)** — текст самого
  джерела внутрішньо суперечливий (фіксована доза чи діапазон?). Процитовано
  дослівно, не виправлено.
- Усі дози з мг/фунт (Amoxicillin, Carprofen, Oxytetracycline, Flunixin,
  Phenylbutazone) перераховані в мг/кг арифметично (коефіцієнт 2.2046), не
  клінічно. Оригінал у фунтах завжди збережений в `original_text`.
- **Flunixin meglumine (Banamine) у ВРХ схвалений ЛИШЕ для в/в введення** —
  джерело прямо каже, що в/м введення спричиняло незаконні залишки в
  їстівних тканинах. Внесено як absolute-контраіндикацію, не просто
  застереження.
- **Praziquantel** (обидва продукти) дозується таблицями "маса тіла ->
  кількість таблеток", без мг/кг у самому джерелі. `dose_min`/`dose_max`
  розраховані арифметично (к-ть таблеток × відома концентрація) і виражені
  в `mg_per_animal`, а не `mg_per_kg` — це найточніше відображення
  реального джерела, без домислювання діапазону мг/кг.
- **Ceftiofur у свиней**: термін виведення залежить від об'єму ін'єкції на
  одне місце (≤5 мл -> 4 доби, >5-15 мл -> 6 діб) — внесено як два окремі
  записи, лікар має обрати правильний за фактичним об'ємом.
- **Oxytetracycline (Agrimycin 200) не має овець у переліку видів** —
  джерело прямо перелічує лише ВРХ і свиней; вівці не додані.
- **Xylazine, Ketamine, Dexamethasone — знайдені продукти покривають менше
  видів, ніж очікувалось у початковому списку.** Конкретні знайдені
  FDA-етикетки: Xylazine Injection - лише коні та Cervidae (олені; олені не
  входять у перелік видів проєкту); Ketaset (ketamine) - лише коти та
  "subhuman primates" (примати не входять у перелік видів проєкту);
  Dexamethasone Injection 2 mg/mL - лише ВРХ і коні, з фіксованою дозою на
  тварину (не мг/кг). Дозування для собак/котів/ВРХ цих трьох речовин, яке
  очікувалось у первинному списку, у цьому пакеті НЕ знайдено - можливо,
  існують окремі продукти для інших видів, які варто пошукати окремо.
- **Ketamine — контрольована речовина** (DEA Schedule III у США; в Україні
  аналогічний режим предметно-кількісного обліку). Дані про дозу зібрані
  коректно з офіційного джерела, але обіг препарату в клініці регулюється
  окремо від цього дозового калькулятора.
- **Doxycycline (систематичне дозування) НЕ знайдено взагалі.** Єдиний
  FDA-схвалений ветеринарний продукт з доксицикліном - Doxirobe Gel
  (Zoetis/Heska), локальний гель для лікування пародонтозу у собак,
  застосовується субгінгівально в пародонтальну кишеню, а НЕ системно за
  вагою тіла (мг/кг) - тому не підходить під модель дозового калькулятора
  "доза за масою тіла" і не внесений як кандидат. Системне застосування
  доксицикліну у дрібних тварин у США є повністю позарегламентним
  (off-label, застосування людського препарату) - офіційної FDA-етикетки з
  мг/кг для собак/котів не існує. Дози з неофіційних сайтів (GoodRx,
  PetMD тощо) свідомо НЕ використані - вони нижче дозволеного рівня джерел.

## Не знайдено

- **Держреєстр ветеринарних препаратів України** (data.gov.ua /
  dpss.gov.ua) — набір даних існує у відкритому доступі, але в цьому
  пакеті не був напряму завантажений і опрацьований (потрібен окремий
  прохід із завантаженням датасету, а не лише пошуком про нього).
- **Meloxicam для ВРХ, свиней, коней** — джерело не відкрито успішно.
- **Ivermectin для овець** (UK VMD SPC не читається) та **для коней**
  (жодне з двох перевірених джерел коней не згадує).
- **Enrofloxacin для котів/собак** — тільки таблетки перевірені; ін'єкційна
  форма для дрібних тварин (якщо існує окремий продукт) не шукалась.
- **Oxytetracycline для овець** — окремий продукт для овець не шукався в
  цьому пакеті.
- **Ceftiofur для дрібних тварин (собаки/коти)** — у цьому пакеті шукався
  лише продукт для ВРХ/свиней.
- **Xylazine для собак/котів/ВРХ** — знайдений продукт покриває лише коней
  і оленів; окремий продукт для дрібних тварин/ВРХ не шукався.
- **Ketamine для собак/коней** — знайдений продукт (Ketaset) покриває лише
  котів; окремий продукт для собак/коней не шукався.
- **Dexamethasone для собак/котів** — знайдений продукт покриває лише ВРХ і
  коней; окремий продукт або дозування для дрібних тварин не шукались.
- **Metronidazole для котів** — знайдений продукт (Ayradia) лише для собак.
- **Doxycycline (системне дозування для собак/котів)** — не знайдено
  жодного FDA-схваленого ветеринарного продукту із системним мг/кг
  дозуванням (див. "⚠️ Потребує особливої уваги").
